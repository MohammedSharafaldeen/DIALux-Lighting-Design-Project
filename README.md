# Indoor Lighting Design Using DIALux evo

## Project Overview

This project presents the design and simulation of indoor lighting systems using DIALux evo.

The lighting design was developed for several indoor spaces, including:

- Office areas
- Conference room
- Corridors

The project focused on achieving suitable illumination levels, improving lighting uniformity, and evaluating the performance of the selected luminaires.

## Software

- DIALux evo
- AutoCAD / DWG architectural drawings

## Project Scope

The main tasks performed during the project included:

- Importing architectural DWG drawings into DIALux evo
- Scaling and aligning floor plans
- Creating building and room contours
- Defining indoor spaces
- Assigning materials and room properties
- Creating working planes and calculation surfaces
- Selecting suitable luminaires
- Creating lighting layouts
- Performing lighting calculations
- Evaluating illuminance levels
- Evaluating lighting uniformity
- Checking glare and UGR conditions
- Adjusting luminaire positions to improve lighting performance
- Generating lighting calculation reports

## Design Parameters

- Working plane height: 0.8 m
- Indoor lighting calculations
- Illuminance analysis
- Uniformity analysis
- UGR / glare evaluation
- Luminaire layout optimization

## Designed Areas

### Office

A lighting system was designed for the office area using ceiling-mounted luminaires.  
The layout was adjusted to provide adequate illumination across the working plane while maintaining good uniformity.

### Conference Room

The conference room lighting design included evaluation of:

- General room illumination
- Conference table lighting
- Working-plane illuminance
- Uniformity
- Glare conditions

Luminaire placement was adjusted based on the simulation results.

### Corridor

The corridor lighting layout was designed to provide sufficient and relatively uniform illumination along the circulation path.

## Lighting Analysis

The DIALux simulations were used to evaluate:

- Average illuminance
- Minimum illuminance
- Maximum illuminance
- Lighting uniformity
- Working-plane illumination
- Luminaire distribution
- UGR / glare considerations
